Servidor con frameword 'express', en archivo index.ts
1.- Luego de clonar el repositorio, asegurese de tener instalado 'pnpm'
    npm install pnpm
2.- Ahora puede instalar todo con:
    pnpm install
3.- Para toda la documentación de los endpoints, en la ruta: 'http://localhost:3000/api-docs/'
    pnpm swagger
4.- Para levantar el servidor
    pnpm dev
    (para salir, presionar las teclas: 'Ctrl + c')
5.- (opcional) Si deseas tambien puedes cargar un link para la web con VisualStudioCode, 
    add Ports - public
